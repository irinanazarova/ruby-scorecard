This guide explains how to add AnyCable to a Ruby on Rails application so that your app can deliver real-time features, and it walks through the requirements, installation, and configuration you need to get started. Before diving into the steps, it helps to understand the terms involved. A WebSocket is a network protocol that keeps a persistent, two-way connection open between a browser and a server, which lets the server push updates to the client the moment they happen rather than waiting for the client to ask. A real-time server is the long-running process that holds these WebSocket connections open and relays messages between connected clients and your application. AnyCable is one such real-time server for Ruby applications, and it is designed to work as a drop-in replacement for Action Cable, the real-time framework that ships with Rails.

Because AnyCable supports most Action Cable features and works with any existing Action Cable client, you can adopt it without rewriting the front-end code that already talks to your channels. AnyCable also adds capabilities that plain Action Cable does not provide, including support for stream history, which lets clients catch up on messages they missed, and a set of API extensions for building richer real-time behavior. If you want to see what moving an existing app looks like in practice, the documentation includes a demonstration of migrating from Action Cable to AnyCable.

To follow this guide, your environment should meet a few minimum requirements: Ruby version 2.7 or newer and Rails version 6.0 or newer. AnyCable delivers broadcast messages from your Rails application to the real-time server through a broadcast adapter, and the adapter you choose has its own requirements; if you want to keep things simple at first, you can begin with the HTTP adapter, which avoids pulling in additional dependencies.

Installation starts by adding the AnyCable gem to your Gemfile, and the package you choose depends on how your Rails application will communicate with the AnyCable server. You then run an interactive setup generator that asks a few questions and configures AnyCable for your application automatically, or you can follow the manual setup section if you prefer full control over each setting. The sections that follow cover each of these steps in detail.
