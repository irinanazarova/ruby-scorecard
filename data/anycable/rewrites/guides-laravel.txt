This guide explains how to use AnyCable as the WebSocket server for a Laravel application, so that you can deliver real-time updates to the browser through Laravel Echo and Laravel's broadcasting system. Before diving into the configuration, it helps to define the core terms. A WebSocket is a persistent, two-way network connection between a browser and a server that stays open so either side can send messages at any moment, which is what makes live features such as chat, notifications, and dashboards possible. A real-time server is the long-running process that holds all of these open connections and pushes messages out to the right clients as events happen in your application. AnyCable is one such real-time server: it accepts WebSocket connections, manages subscriptions, and broadcasts messages, and it has run in production at scale for many years while offering reliability features, support for several protocols, observability tools, and free use.

In a Laravel project, AnyCable works as a drop-in replacement for the WebSocket server you already rely on, whether that is Laravel Reverb, Pusher, or another service. There are two ways to connect the two systems, and this guide covers both. The first approach, called Pusher mode, lets AnyCable speak the same protocol that Reverb and Pusher use, so your existing Echo configuration keeps working with little more than a change to the command that starts the server. The second approach, called AnyCable mode, uses a dedicated broadcasting driver together with a custom Echo adapter built on the AnyCable JavaScript SDK. Choosing this native path unlocks features that the Pusher protocol does not expose, most notably reliable streams, which include stream history and resumable sessions, so a client that briefly loses its connection can reconnect and receive the messages it missed.

The sections that follow walk through each mode in turn. For Pusher mode, you will swap the Reverb start command for the AnyCable equivalent and confirm that the server listens on its default port. For AnyCable mode, you will install the Laravel broadcaster package, register the AnyCable service provider and broadcasting driver, install and configure the matching Echo package in your frontend, and finally run the AnyCable server through a provided Artisan command that can download the binary when needed. Throughout, each command and configuration change is explained in context so you understand not only what to run but why it is required.
