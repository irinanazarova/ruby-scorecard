This guide explains how to use AnyCable to add real-time features to a serverless JavaScript or TypeScript application, and it walks through the pieces you need to deploy and connect them together. Before we begin, it helps to define the key terms. AnyCable is a real-time server: a long-running process that maintains persistent connections with clients, typically over the WebSocket protocol, so that a server can push messages to browsers the moment something changes rather than waiting for the browser to ask. A WebSocket is a connection that stays open in both directions, which is what makes live chat, notifications, and collaborative updates possible. Serverless, by contrast, describes an application built from short-lived functions that spin up to handle a request and then shut down, which means a serverless function cannot itself hold a connection open for minutes or hours. AnyCable bridges this gap by handling the persistent connections on your behalf while your serverless functions continue to hold all of your application logic.

The appeal of this arrangement is that you keep your code in one place and avoid the usual costs of adding real-time features. AnyCable acts as a real-time server with no strings attached, which means no vendor lock-in, no tangle of extra microservices, and no surprise platform bills. Your job is to let AnyCable handle the low-level connection work so that your JavaScript application can stay focused on what it does best.

Getting AnyCable working with a serverless application involves three main steps that the rest of this guide expands on in detail. First, you deploy an AnyCable server to a hosting platform of your choice. Second, you configure an AnyCable API handler inside your JavaScript application so the server has somewhere to send incoming events. Third, you use the AnyCable Client SDK to communicate with the server from the browser. Once these pieces are in place, AnyCable manages the WebSocket and SSE connections and translates incoming commands into API calls to your serverless functions, where you can manage subscriptions and respond to client commands. Broadcasting a real-time update then becomes as simple as sending an HTTP POST request to AnyCable. You will not need to write all of this from scratch, because the AnyCable JavaScript SDK provides ready-made helpers for authentication, signed streams, broadcasting, and channels that make the integration straightforward.
