This guide explains how to install AnyCable, run its server, and connect a client to it, so that you can begin building real-time features for your application. AnyCable is a real-time server: a long-running program that maintains persistent connections with many web clients at once and pushes messages to them instantly, rather than requiring each client to repeatedly ask for updates. It is written in the Go programming language and described as language-agnostic, meaning that although it integrates closely with Ruby applications, it is not tied to any single programming language on the application side. Its design emphasizes performance and reliability when handling large numbers of simultaneous connections.

The server component is called anycable-go. The most direct way to obtain it is to download a pre-compiled binary, a ready-to-run executable that requires no compilation on your machine. On macOS the binary can be installed through the Homebrew package manager, and on Arch Linux it is available through the AUR. For JavaScript and TypeScript projects, AnyCable-Go can also be installed as an NPM package, in which case the matching server binary is downloaded automatically the first time the command runs. Once installed, the server is started simply by running anycable-go, after which it prints startup information and begins listening for connections.

A central idea behind AnyCable is that the server itself contains no business logic. It acts as a proxy that forwards work to a separate backend, which authenticates connections, authorizes subscriptions, and processes incoming messages. By default the server expects this backend to be a gRPC server, a remote procedure call service, listening on localhost port 50051, which is the standard location used by the companion Ruby library. For situations that only need publish and subscribe messaging, AnyCable can instead run in a standalone mode without any backend, using token-based authentication and signed message streams to control access. Clients communicate with the server using the Action Cable protocol, and an official JavaScript client library is provided so that web applications can subscribe to channels and exchange messages with the server.
