Action Policy is a Ruby library that helps you decide who is allowed to do what in your application. This guide introduces its core ideas so you can add authorization to a Ruby or Ruby on Rails project. Authorization is the process of determining whether a given user is permitted to perform a given action on a given resource, such as viewing, editing, or deleting a record. It is distinct from authentication, which establishes who the user is; authorization assumes the user is already known and asks what that user may do.


The central concept in Action Policy is the policy class. A policy class is an ordinary Ruby class that describes the access rules for a single kind of resource. The recommended convention is to create one policy per resource and name it after the model with a Policy suffix, so that a Post model is governed by a PostPolicy; in Rails these classes live in the app/policies folder. Within a policy, each rule is a public method whose name is the predicate form of an action, such as show? or update?, returning true when the action is permitted and false when it is not. Rules must be public, since private methods raise an error. It is common to define an ApplicationPolicy base class that holds shared configuration and to have other policies inherit from it.

Inside a rule you have access to two values that Action Policy provides automatically. The first, called user, is the subject performing the action, by default the currently authenticated user. The second, called record, is the target object being acted upon. A rule combines these to reach its decision; an update rule might permit the change only when the user is an administrator or owns the record.

Once policies are defined, you enforce them by calling a method that checks the relevant rule. When the rule returns true, execution continues normally; when it returns false, Action Policy raises an unauthorized error you can rescue and handle. Action Policy can usually infer which policy and rule to apply from the resource and action name, while still letting you name them explicitly when needed.
