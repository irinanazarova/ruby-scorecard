Most ways to store a tree in a relational database trade away either fast reads or fast writes, but the Closure Table pattern keeps both. A tree, also called a hierarchical data structure, is a set of records where each node points to a single parent, so the whole shape fans out from one root down through many levels of children, the way regions contain cities and cities contain streets and streets contain houses. PostgreSQL is the open-source relational database that has to answer questions about that shape: not just "who is this node's parent" but "give me every street inside this region" or "walk the full path from this house back up to the root." The Closure Table pattern is a way to store those relationships so that both kinds of query stay fast, by keeping a separate table that records every ancestor-descendant pair in the tree rather than only the immediate parent link. Rails is the Ruby web framework whose ActiveRecord layer maps database rows to objects, and it is where this tree eventually has to live and be queried.

The concrete problem came from a project that set out to systemize a pandemonium of scattered databases, and the hardest of those were the toponym tables, meaning the records of place names. The source was a deep XML tree with regions and cities near the top and streets and houses at the bottom, more than a million unsorted records, each carrying an id, a parent_id pointing at the node above it, and a name. That tree had to go into PostgreSQL so the application could run hierarchical queries against it, and because there were many such queries to serve, every one of them had to come back as fast as possible, since a server that stops responding and a downtime nobody planned for are about the worst outcomes a backend can hand a user. Getting there meant three steps where speed was the only thing that mattered: importing the raw table efficiently, choosing the hierarchical storage pattern that fit these queries, and then computing the extra reference data that the chosen pattern depends on to do its work.
